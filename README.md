# SapnaGul_SoftGrowTech
Basic Chatbot – Task 4
Description

This project is a simple rule-based chatbot developed in Python.
The chatbot responds to specific user inputs with predefined replies using conditional statements.

Features

Takes user input from console

Responds to predefined messages

Runs in a loop until user types "bye"

Simple and text-based interaction

Supported Inputs and Responses

hello → Hi!

how are you → I'm fine, thanks!

bye → Goodbye!

If the input does not match predefined responses, the chatbot replies:
"I don't understand that."

Concepts Used

if-elif statements

functions

while loop

input/output

Object-Oriented Programming (Class)

How to Run

Open terminal or command prompt.

Navigate to the project folder.

Run the command:

python BasicChatbot.py  

Type messages like "hello", "how are you", or "bye".
